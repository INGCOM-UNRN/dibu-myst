# dibu-myst

Este sitio muestra el plugin [dibu-myst](https://github.com/INGCOM-UNRN/dibu-myst): los
diagramas de [dibu](https://github.com/INGCOM-UNRN/dibu) se dibujan al construir el sitio, sin
SVG pregenerados ni binarios instalados.

Un bloque de código `estructura`, como los de los apuntes y los bancos de alucarD:

```estructura
type: linked_list
title: Lista enlazada simple
values: [12, 25, 8]
```

El [apunte de ejemplo](apunte.md) usa la directiva `{dibu}` con figuras, themes y archivos.
